# Java Banking System

A simple, interactive console-based banking application built in Java. This project demonstrates foundational object-oriented programming principles, data input handling using Java's `Scanner`, and control flow structures like `do-while` loops and `switch` cases.

## Features
* **Check Balance:** Instantly view your current account balance.
* **Deposit Funds:** Add money securely to your account.
* **Withdraw Funds:** Take money out of your account with real-time balance tracking.
* **Interactive Menu:** A clean, repeatable command-line menu interface.

## How It Works
The application uses a loop to keep the banking menu running continuously until the user explicitly selects the exit option (`0`). It actively updates a running `double balance` variable in memory based on the user's transaction choices.
